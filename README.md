```
کاربر ──TLS:443──► Railway Edge ──► nginx :8080 ─┬─► /dashboard  /api  /sub   ► Marzban :8000
                                                ├─► /panel-ws  (HTTPUpgrade) ► 🔒 جینکس | 𝙎𝙪𝙥𝙚𝙧 𝗝𝗶𝗻𝗫
                                                ├─► /vless     (WS)          ► VLESS
                                                ├─► /vmess     (WS)          ► VMess

```

TLS رو خود Railway روی 443 می‌زنه. پس داخل کانتینر هیچ سرتیفیکیتی لازم نیست و هیچ‌وقت هم منقضی نمیشه.

## 🚀 شروع سریع (۵ دقیقه)

**۱. ریپو**
همه‌ی فایل‌ها رو توی یه ریپوی گیت‌هاب (Private بهتره) آپلود کن.

**۲. پروژه**
توی Railway برو به **New Project ← Deploy from GitHub repo** و ریپو رو انتخاب کن.

**۳. ریجن** ⚡
از **Settings ← Region** گزینه‌ی **EU West (Amsterdam)** رو انتخاب کن، چون برای ایران کمترین پینگ رو داره.

**۴. متغیرها**
برو به **Variables ← Raw Editor** و محتوای `variables.env` رو پیست کن.

**۵. Volume** 💾
روی سرویس کلیک راست کن و **Attach Volume** رو بزن. Mount path رو بذار:
```
/var/lib/marzban
```

**۶. دامنه** 🌐
برو به **Settings ← Networking ← Generate Domain** و برای پورت بنویس:
```
8080
```

**۷. Redeploy**
یه بار Redeploy بزن تا دامنه وارد کانفیگ‌ها بشه. تمومه 🎉

```
پنل:   https://xxxx.up.railway.app/dashboard/
ورود:  admin / admin
```

## ⚙️ متغیرها

| متغیر | مقدار | توضیح |
|---|---|---|
| `PORT` | `8080` | پورت داخلی، هیچ‌وقت عوضش نکن |
| `UVICORN_HOST` | `127.0.0.1` | پنل فقط از پشت nginx در دسترسه |
| `UVICORN_PORT` | `8000` | پورت داخلی مرزبان |
| `SUDO_USERNAME` | `admin` | یوزر ادمین اصلی |
| `SUDO_PASSWORD` | `admin` | ⚠️ بعد از اولین ورود عوضش کن |
| `XRAY_JSON` | `/var/lib/marzban/xray_config.json` | کانفیگ Xray روی Volume |
| `SQLALCHEMY_DATABASE_URL` | `sqlite:////var/lib/marzban/db.sqlite3` | دیتابیس روی Volume |
| `PANEL_DOMAIN` | *(اختیاری)* | اگه دامنه‌ی شخصی وصل کردی، اینجا بنویسش |

> `XRAY_SUBSCRIPTION_URL_PREFIX` لازم نیست. خودش از `RAILWAY_PUBLIC_DOMAIN` پر میشه.

## 🔒 اینباند قفل‌شده

اینباند **جینکس | 𝙎𝙪𝙥𝙚𝙧 𝗝𝗶𝗻𝗫** (VLESS + HTTPUpgrade روی `/panel-ws`) سه لایه محافظت داره:

1. **Core Settings فقط‌خواندنیه.** nginx هر درخواستی برای تغییر کانفیگ Xray رو با `403` رد می‌کنه.
2. **ری‌استارت = ریست.** `lock.py` موقع هر استارت اینباند رو از روی ایمیج دوباره می‌نویسه.
3. **نگهبان Hosts.** `enforce_hosts.py` هر ۲۰ ثانیه اسم، آدرس، SNI و TLS این اینباند رو چک می‌کنه و اگه دستکاری شده باشه برش می‌گردونه.

اسم همه‌ی کانفیگ‌های این اینباند توی کلاینت همیشه همینه: **جینکس | 𝙎𝙪𝙥𝙚𝙧 𝗝𝗶𝗻𝗫**

> برای تغییر اینباندها فقط ریپو رو ادیت کن و Redeploy بزن.

## 🌀 تانل کلودفلر (پینگ پایین و ثابت)

مستقیم روی Railway، کاربر تا اروپا میره و برمی‌گرده. با تانل، کاربر به **نزدیک‌ترین سرور کلودفلر** وصل میشه و از اون‌جا ترافیک از یه مسیر ثابت به Railway (هلند) می‌رسه.

```
کاربر ──► Cloudflare Edge (نزدیک ایران) ══ Tunnel ══► Railway Amsterdam :8080
```

**راه‌اندازی:**

1. یه دامنه به کلودفلر وصل کن (دامنه‌ی ارزون هم کافیه).
2. برو به **Zero Trust ← Networks ← Tunnels ← Create a tunnel**، نوع **Cloudflared** رو انتخاب کن و **توکن** رو کپی کن.
3. توی **Public Hostname** یه ساب‌دامین بساز (مثلاً `jinx.yourdomain.com`) و Service رو بذار روی:
   ```
   HTTP  →  localhost:8080
   ```
4. این متغیرها رو توی Railway اضافه کن و Redeploy بزن:

| متغیر | مقدار |
|---|---|
| `CF_TUNNEL_TOKEN` | توکن تانل |
| `CF_TUNNEL_HOSTNAME` | `jinx.yourdomain.com` |
| `CF_CLEAN_IP` | *(اختیاری)* آی‌پی تمیز کلودفلر برای اپراتور خودت |

از این به بعد ساب‌لینک خودش دو تا کانفیگ میده:
- **جینکس | 𝙎𝙪𝙥𝙚𝙧 𝗝𝗶𝗻𝗫** که از تانل کلودفلر رد میشه ⚡
- **جینکس | 𝙎𝙪𝙥𝙚𝙧 𝗝𝗶𝗻𝗫 ⚡ Direct** که مستقیم به Railway وصل میشه و پشتیبانه

> توی حالت تانل، **Clean IP کلودفلر کار می‌کنه** و همین‌جاست که پینگ پایین میاد. چند تا آی‌پی رو روی اپراتور خودت تست کن و بهترینش رو بذار توی `CF_CLEAN_IP`.

## 🛠 عیب‌یابی

| مشکل | راه‌حل |
|---|---|
| دیپلوی روی Healthcheck فیل میشه | Target Port دامنه باید **8080** باشه. هلث‌چک خود پنل رو تست می‌کنه، پس اگه فیل شد لاگ `alembic` یا `main.py` رو ببین |
| توی لاگ `domain: NOT SET` میاد | Generate Domain بزن و Redeploy کن |
| ساب‌لینک کانفیگ با `{SERVER_IP}` میده | ۲۰ ثانیه صبر کن و ساب رو آپدیت کن، نگهبان خودش درستش می‌کنه |
| لاگ‌های زنده‌ی پنل باز نمیشه | صفحه رو رفرش کن، WebSocket پنل از قبل توی nginx فعاله |
| بعد از ری‌استارت یوزرها می‌پرن | Volume روی `/var/lib/marzban` نیست |
| ذخیره‌ی Core Settings ارور `403` میده | عمدیه 🔒 از ریپو ادیت کن |
| کلاینت وصل میشه ولی چیزی باز نمیشه | Mux رو خاموش کن، IP تمیز کلودفلر نزن |
| پنل باز نمیشه | آدرس رو با `/dashboard/` باز کن |

> ⚠️ توی **حالت مستقیم**، Clean IP کلودفلر کار نمی‌کنه و پورت هم فقط **443** هست. Clean IP فقط توی **حالت تانل** کار می‌کنه.

| مشکل تانل | راه‌حل |
|---|---|
| توی لاگ `[tunnel]` ارور توکن میاد | توکن رو کامل و بدون فاصله کپی کن |
| کانفیگ تانل وصل نمیشه | Service توی Public Hostname باید `HTTP localhost:8080` باشه |
| پینگ بالاست | یه Clean IP دیگه رو توی `CF_CLEAN_IP` تست کن |
